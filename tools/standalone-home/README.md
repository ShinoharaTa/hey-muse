# Echo Show 5 の本体連携

待機画面は、本体の `127.0.0.1:50226` に接続します。SwitchBot の状態と家電操作には SwitchBot API v1.1 を使います。Google カレンダーは2件の iCal 購読から、今後7日間の予定を約5分ごとに取得します。取得に失敗した場合は前回の予定と「更新待ち」を表示します。

「明日の予定を教えて」「廊下の電気を消して」などの定型句には、本体で音声認識と操作を行い、保存した日本語音声で結果を返します。一般の Muse 会話と自由文の読み上げは従来の接続先を使います。

## 実機での確認

USBコンソールで次を実行すると、センサー、ボタン、カレンダーの更新、声で操作する機器の対応を確認できます。家電の電源やシーンを変更する命令は送信しません。

```sh
cd /data/misc/techo5/standalone-home
./home-python probe.py
```

本体上の `calendar-feeds.txt` は「メイン」「二人」の順に1行1件です。格納先は管理者だけが読めるディレクトリです。Google 側で非公開URLを再発行した場合は本体側の該当行も更新してください。
